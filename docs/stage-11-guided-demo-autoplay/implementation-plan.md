# Stage 11 - Implementation Plan

## 1) Запуск и состояние тура

1. Кнопка запуска демо в главном меню.
2. Состояние тура хранится в `localStorage`:
   - текущая фаза (`themes`/`editor`)
   - индекс шага
   - флаг паузы
   - id демо-сущностей

## 2) Seed-этап (идемпотентный)

1. Upsert демо-темы.
2. Upsert демо-презентации.
3. Пересборка демо-слайдов и датасета.
4. Подготовка списка тем для этапа «сравнение на 2x2».

## 3) Guided flow в редакторе тем

1. Инфо-шаги по зонам: выбор темы, основные токены, опциональный декор.
2. Action-шаги:
   - изменение палитры/типографики
   - переключение сцен превью
   - включение/выключение декора
   - применение темы к демо-презентации
3. Автопереход в редактор презентации.

## 4) Guided flow в редакторе презентации

1. Инфо-шаги: структура слайдов, блоки, свойства/лейаут.
2. Action-шаги:
   - переход на слайд конструктора
   - очистка и автодобавление блоков всех типов
   - редактирование графика/таблицы/изображения
   - обновление превью и автоскролл на нужный слайд
3. Переход на слайд 2x2 и смена 2-3 тем с длинной паузой.
4. Подсветка и объяснение 3 кнопок экспорта.

## 5) Тайминги и читаемость

1. Info-шаги: длинные задержки (ориентир 6-8 секунд).
2. Action-шаги: статус действия + задержка после выполнения.
3. Подсказка скрывается на время автодействия и снова показывается.

## 6) Риски и защита

1. Хрупкость DOM-селекторов:
   - использовать стабильные `data-demo`.
2. Долгие операции:
   - показывать статус в подсказке.
3. Повторный запуск:
   - строго идемпотентный seed.
