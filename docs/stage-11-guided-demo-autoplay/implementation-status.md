# Stage 11 - Implementation Status

## Текущий статус

Implemented (v2), готово к ручной проверке.

## Что сделано

1. Подсказка тура перенесена в центр экрана.
2. Реализован цикл шага:
   - показать объяснение
   - скрыть подсказку
   - выполнить автодействие
   - вернуть подсказку
3. Увеличены задержки для читаемости.
4. Добавлены подробные шаги:
   - в редакторе тем
   - в редакторе презентаций
5. Улучшен автоскролл превью к нужному слайду (с повторными попытками).
6. В конструкторе показаны:
   - добавление всех основных типов блоков
   - автоматический выбор лейаута и назначение блоков по слотам
   - редактирование графика, таблицы, изображения
   - смена тем на 2x2 с увеличенной паузой
7. Обновлена документация stage-11.
8. Перед применением тема автоматически сохраняется в БД, чтобы изменения из редактора точно попадали в демо-презентацию.
9. В сценарии смены тем убрана «стандартная» тема из витрины (используются более контрастные варианты).
10. В шаге редактора тем добавлены безопасные сочетания цветов для графиков/таблиц на светлой подложке (читаемые подписи и оси).
11. В шаге конструктора добавлена демонстрация изображения: кроп (`cover`), фокус и смещения (`offsetX/offsetY`) в реальном времени.

## Что проверить вручную

1. Текст подсказок успевается прочитать на каждом этапе.
2. Превью не застревает на титульном слайде.
3. На этапе 2x2 тема переключается с заметной паузой.
4. Кнопки экспорта только подсвечиваются, без автоскачивания.

## Остаточные риски

1. При сильной перестройке DOM могут сломаться селекторы подсветки.
2. На медленном окружении отдельные action-шаги могут выполняться дольше ожидаемого тайминга.
