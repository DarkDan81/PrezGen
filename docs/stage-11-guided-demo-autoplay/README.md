# Stage 11 - Guided Demo Autoplay

## Цель

Сделать демонстрационный автогайд «одна кнопка -> понятный walkthrough», где пользователь успевает читать подсказки и видит, как продукт сам:

1. Создает демо-тему и демо-презентацию.
2. Показывает редактирование темы в реальном времени.
3. Показывает работу конструктора (добавление/редактирование блоков).
4. Демонстрирует быструю смену тем на слайде 2x2.
5. Подсвечивает кнопки экспорта (без автоскачивания).

## Принципы UX для автогайда

1. Подсказка находится по центру экрана.
2. Формат шага: «объяснение -> скрытие подсказки -> автодействие -> возврат подсказки».
3. Тайминги увеличены, чтобы текст можно было прочитать (длинные паузы на info-шаге).
4. В action-шаге показывается статус текущего действия.
5. Автоскролл ведет пользователя к релевантному слайду и месту в интерфейсе.

## Scope

В scope:

1. Запуск демо одной кнопкой из главного меню.
2. Идемпотентный seed демо-темы и демо-презентации.
3. Подробный guided-flow на страницах:
   - `/themes`
   - `/presentations/:id`
4. Автопереход между страницами без ручных кликов.
5. Демонстрация всех ключевых типов блоков:
   - текст
   - изображение
   - график
   - таблица
   - карточки
6. Демонстрация смены темы на слайде 2x2 с увеличенной задержкой.

Вне scope:

1. Голосовое сопровождение.
2. Полный E2E pixel-diff по фронтенду.
3. Автоматическое скачивание файлов в guided-режиме.

## Критерии приемки

1. Подсказки читаемы по времени (без «мгновенного» перелистывания).
2. В теме и в конструкторе есть пошаговое объяснение ключевых зон интерфейса.
3. В конструкторе автогайд показывает добавление и редактирование блоков.
4. При показе 2x2 слайда тема переключается с заметной паузой для сравнения.
5. Превью прокручивается на актуальный слайд, а не остается на титульном.
6. Экспорт только подсвечивается и объясняется.
