# Stage 3 Decisions (Approved)

Date: 2026-02-26

## UI Stack

1. No UI component library for MVP.
2. Use custom React components + CSS (CSS Modules and tokens).

## Save Behavior

3. Autosave is enabled with debounce.
4. Invalid forms are not saved.

## Preview Experience

5. Preview is embedded in iframe inside editor (not new tab).

## Constructor Theme

6. Constructor supports both light and dark mode in MVP.

## Reorder UX

7. Drag-and-drop uses explicit drag handles (not full-row drag).

## Validation UX

8. Validation is strict and blocking for save actions.

## Notes

9. Draft/published versioning remains backend concern; rollback UX for users can be added later in frontend.
