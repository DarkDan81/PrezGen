## 4. Текстовый блок (HTML)

- [ ] Открыть текстовый блок и проверить, что доступен режим `Визуально` и режим `Код`
- [ ] В режиме `Визуально` проверить жирность/курсив/списки/заголовок/ссылку
- [ ] В режиме `Визуально` проверить выбор цвета: через theme-swatches и через color picker
- [ ] Переключиться в `Код`, отредактировать HTML вручную и нажать `Применить HTML`
- [ ] Вставить HTML-пример (ниже) в текстовый блок (режим `Код`)
- [ ] В превью корректно отображаются заголовки/списки/акценты
- [ ] `Обновить превью` показывает актуальный контент

### HTML-Пример Для Вставки

```html
<h3>Q1 Summary</h3>
<p><b>Revenue:</b> 450,000</p>
<ul>
  <li class="bullet">January growth: 12%</li>
  <li class="bullet">February growth: 18%</li>
  <li class="bullet">March growth: 9%</li>
</ul>
<h3>Notes</h3>
<p>Focus on conversion, repeat purchases, and average order value.</p>
```

## 16. QA Demo Deck (Эталонная Тестовая Презентация)

Предусловия:

- [ ] Выполнить `npm run seed:qa-demo`
- [ ] Открыть презентацию с именем `QA Demo Deck`

Целостность слайдов и контента:

- [ ] Слайд `Single Column`: используется только текстовый контент (без вторичного блока-карточек)
- [ ] Слайд `Two Columns`: длинный токен текста остается внутри левой колонки (нет overflow за границы блока)
- [ ] Слайд `2x2 Grid`: карточки аккуратно помещаются в слот и не перекрываются
- [ ] Слайд `Content + 3 Images Right`: все 3 изображения отображаются целиком (без кропа) и с ровным фреймингом
- [ ] Слайд `3 Images Left + Content`: то же поведение без кропа в зеркальном варианте
- [ ] Слайд `Content + 4 Images Right`: все 4 ячейки изображений без клиппинга/перекрытий
- [ ] Слайд `4 Images Left + Content`: то же поведение в зеркальном варианте
- [ ] Слайд `Content + 2 Vertical Images Right`: обе вертикальные картинки читаемы и без кропа
- [ ] Слайд `Content + Vertical + 2 Horizontal`: вертикальная и две горизонтальные отображаются корректно в своих слотах

Новые настройки блока изображения:

- [ ] Открыть image-блок и переключить `Image fit` на `Cover` -> изображение заполняет слот (кроп допустим)
- [ ] Вернуть `Contain` -> изображение снова видно целиком без кропа
- [ ] Изменить `Image focus` на угловые значения и проверить смещение фокуса в режиме `Cover`
- [ ] Изменить `Масштаб` и проверить плавное увеличение/уменьшение внутри слота
- [ ] Изменить `Смещение X/Y` и проверить позиционирование в режиме `Cover`
- [ ] При переключении обратно в `Contain` изображение не остается обрезанным
- [ ] Убедиться, что вокруг изображений в кластерах нет служебных рамок и подложек

## 17. Удобство Рабочей Области Редактора (Phase 8)

- [ ] Верхняя панель редактора всегда в компактном виде (без сворачивания/разворачивания)
- [ ] В верхней панели слева: `К списку`, название текущей презентации, `Обновить превью`
- [ ] Статус сохранения/рендера отображается по центру верхней панели
- [ ] В верхней панели справа: переключатель UI-режима, компактные селекты языка и темы, выделенная кнопка `Экспорт PDF`
- [ ] Селекты языка и темы имеют одинаковую компактную ширину и не растягиваются
- [ ] Скролл левой панели независим от центра и правой панели
- [ ] Скролл правой панели независим
- [ ] Скролл центрального превью независим
- [ ] Кнопка `Обновить превью` всегда доступна в верхнем ряду
- [ ] Переключатель языка отображается как компактный inline-select с флагом (без отдельного блока-лейбла)
- [ ] Настройки блока открываются в левой колонке (под блоками выбранного слайда)
- [ ] Правая колонка содержит только настройки слайда/лейаута/датасетов
- [ ] `Тип слайда` в правой колонке отображается как статичный текст, а не как редактируемое поле
- [ ] В настройках image-блока загрузка файла отображается как единый кастомный контрол (без нативной browser-кнопки)
